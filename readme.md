# HomeDecorAngular

## Описание проекта

- Интернет-магазин комнатных растений, флорариумов, кашпо и предметов декора, разработанный на Angular 21. Приложение взаимодействует с backend через REST API и включает полноценную систему авторизации, личный кабинет пользователя, корзину, избранное, оформление заказов и историю покупок.

> **Примечание:** на текущем этапе проекта реализована только desktop-версия интерфейса.

## Ключевые возможности

- **Авторизация и регистрация.** Реализована регистрация новых пользователей, вход в систему и работа с защищенными разделами приложения.

- **Работа с backend.** Каталог товаров, личные данные пользователя, корзина, избранное и история заказов загружаются через REST API с использованием `HttpClient`.

- **Каталог товаров.** Просмотр товаров по категориям с возможностью перехода в нужный раздел прямо с главной страницы.

- **Фильтрация и сортировка.** Каталог поддерживает сортировку товаров и фильтрацию по категориям.

- **Поиск товаров.** Реализован удобный поиск по каталогу с мгновенным отображением результатов.

- **Карточка товара.** Отображение подробной информации о выбранном товаре.

- **Корзина и избранное.** Добавление и удаление товаров, изменение количества, автоматический пересчет общей стоимости заказа.

- **Оформление заказа.** Заказ можно оформить как авторизованному пользователю, так и гостю без регистрации.

- **История заказов.** Для авторизованных пользователей доступен просмотр ранее оформленных заказов.

- **Реактивные формы.** Форма оформления заказа реализована с использованием `Reactive Forms` и включает полную валидацию пользовательских данных.

- **Пользовательский интерфейс.** После успешного оформления заказа отображается уведомление, после чего пользователь автоматически перенаправляется на главную страницу.

- **Дополнительные компоненты.** На главной странице реализован слайдер на Owl Carousel, подключены Яндекс Карты и блок отзывов.

## Стек технологий

- **Frontend:** Angular 21, TypeScript.
- **HTTP-клиент:** `HttpClient` для взаимодействия с REST API.
- **Формы:** `ReactiveFormsModule`.
- **Реактивность:** RxJS.
- **Маршрутизация:** Angular Router.
- **Стили:** SCSS.
- **Дополнительные библиотеки:** Owl Carousel, Angular Material (Snackbar).

## Запуск проекта

- backend
- `cd backend` && `npm i` && `npm start`

- frontend
- `cd frontend` && `npm i` && `ng serve -o`
